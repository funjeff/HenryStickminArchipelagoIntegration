To play this mod head over to the releases page, download the henry swf files and place them in your henry stickmin folder (C:\Program Files (x86)\Steam\steamapps\common\HenryStickmin for windows users) replace the ones that are already there.

Once you have done that Intstall the apworld from the releases page to your archipelago client and run the henry client 

if you are on windows the client will autodetect the path to your henry stickmin save files (probably C:\Users\{username}\AppData\Roaming\com.innersloth.henry.HenryFlash\Local Store) and create two new files archipelagoIn.sav and archipelagoOut.sav for comunication with The Henry Stickmin Collection

if you are on another system type or it simply doesen't work it will prompt you to provide the path to your save file and you will have to enter it manually
if for any reason you need to change what path your using you can do so with /set_henry/path

after that boot up the game and delete your save file otherwise you will have the whole map unlocked (or whatever portion you already had unlocked)

and thats it as long as the game and client are open at the same time they will speak over the archipelagoIn.sav and archipelagoOut.sav files

have fun :)
